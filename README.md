# JCCM Website

Foundation for the JCCM corporate website, built with Next.js App Router,
TypeScript, React, Tailwind CSS, and ESLint.

## Development

```bash
npm run dev
```

## Validation

```bash
npm run lint
npm run typecheck
npm run build
```

The homepage is intentionally empty. Visual sections, shared UI primitives,
content models, and application features will be added only as their approved
designs and requirements are implemented.
